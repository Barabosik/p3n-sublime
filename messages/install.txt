p3n
===

Thanks for installing p3n. It checks text for AI writing, and rewrites it.

Select some text, then open the command palette (Ctrl+Shift+P, or Cmd+Shift+P
on a Mac) or right-click the selection:

- p3n: Check for AI   A score, a one-line reason, and the sentences that give
                      it away, underlined in your text.
- p3n: Rewrite        A version that keeps your facts and drops the filler.
                      "Replace selection" puts it back; Ctrl+Z undoes it.

You get 10 checks or rewrites an hour without an account, up to 5,000
characters each. For more, make an API key at https://p3n.si/dashboard/keys
and run "p3n: Set API Key".

Privacy: p3n sends the text you selected to api.p3n.si, only when you run one
of its commands. It sends nothing else, keeps no history and has no analytics.
Details: https://github.com/Barabosik/p3n-sublime/blob/main/PRIVACY.md
